# MovieTix

Market-style cinema booking app for Indian cities. Browse now-showing and coming-soon titles, pick a cinema and showtime, lock a hall map (Classic / Prime / Recliner), and collect an M-Ticket with QR.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide icons

## Demo notes

- Payments are simulated. Use card `4242 4242 4242 4242`.
- Promo code: `BOOKNOW10` (10% off tickets).
- Tickets and booked seats persist in the browser (`localStorage`).
- No backend — this is a frontend product demo.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```
